# merchStoreFront

A responsive landing page for a merch and print-on-demand (POD) artwork business, now scaffolded with modern frontend tooling.

## Tooling included

- Vite 6 (dev server + build)
- React 18
- Tailwind CSS + PostCSS + Autoprefixer
- ESLint 9 (flat config)
- Prettier

## Getting started

```bash
npm install
npm run dev
```

## Build and quality scripts

```bash
npm run build
npm run preview
npm run lint
npm run format:check
```
